# Generated stat scaling reference

Status: proposed design, 2026-10-22; no runtime changes or Studio playtest claim.

Generated by [stat-scaling-model.cjs](stat-scaling-model.cjs). Run from the repository root with Node and `--write` to regenerate, or `--check` to verify. The [50-floor CSV](FLOOR_SCALING.csv) contains the complete enemy curve.

## Calculation contract

- Quality `q = 1.00`; rested heroes; no critical hits, Overdrive, exposure, or other damage bonus.
- Hero growth `G = 3^(S-1) * 1.08^(L-1)`; promotion keeps level.
- Weapon power `P = InherentRarityPower * WeaponStarMultiplier`.
- `AttackDamage = round(SeedDamage * q * G * (1 + P/40))`; `HP = round(SeedHP * q * G)`.
- Weapon speed comes from rarity only. `Interval = max(0.20, BaseInterval / ((1 + SpeedBonus) * OverdriveMult))`.
- The conservative 5 Hz model uses `TickInterval = 0.20 * ceil(Interval/0.20)`, with a tiny numerical tolerance at exact tick boundaries. `DPS = AttackDamage/TickInterval`.
- Hero combat stats are movement speed, attack speed, attack damage, and health. Base movement speed is 20 studs/s for every launch hero; it does not receive exponential scaling. Range is targeting metadata; labor is facility output.
- Five copies of Han are the reproducible calibration squad. A mixed squad is checked separately. These are earned builds, not automatic bonuses from entering a floor.
- Interpolate the two bracketing checkpoint DPS values geometrically for every intermediate floor; interpolate reference HP the same way. Enemy health is `round(DPS * [2, 8, 45])` for regular/elite/boss; basic ATK is `round(ReferenceHP * [0.015, 0.030, 0.040])`. Only milestone floors spawn bosses.
